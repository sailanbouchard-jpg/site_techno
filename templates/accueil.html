Comment fonctionne ce site web

Pour afficher cette page web, votre ordinateur utilise le Code Source et il comprend les instructions. Par exemple : « affiche un titre en gras, puis place telle image en dessous ». Vous pouvez voir le code source de cette page, en cliquant sur le bouton droit de la souris et en sélectionnant "Afficher le code source de la page".

Ce code contient un programme : une suite d'instructions que l'ordinateur va exécuter. Pour écrire ce programme, on peut utiliser plusieurs langages de programmation. Ces programmes sont difficiles à lire pour les humains, mais ils contiennent toutes les informations nécessaires pour que l'ordinateur affiche correctement la page.

La majorité des sites web utilisent trois langages de programmation différents : le HTML, le CSS et le JavaScript. Chaque langage permet de réaliser des choses différentes :

Le HTML : Il permet de placer des éléments sur une page, par exemple un paragraphe, un titre, une image, un bouton. On place les éléments les uns après les autres, et on dispose le contenu du site.

Le CSS : Une fois les éléments placés avec le HTML, on utilise le CSS pour modifier leur apparence. On peut changer la couleur d'un élément, sa taille, la position. c'est grâce au CSS que les boutons changent de couleur lorsqu'on clique dessus.

Le JavaScript : On utilise le JavaScript (js) pour rendre la page interactive. C'est utile pour créer des animations, des jeux et tout ce qui sera interactif. Le système de comptes élèves de ce site est construit en utilisant du JavaScript.

Voici une démonstration d'un programme écrit en HTML.

<p>Ma première page web.</p>
<p>je peux écrire ce que je veux sur la page.</p>
