Cours, travaux pratiques, entraînements et outils.

Comment ce site est fait

Serveur Python avec Flask ; les réponses des élèves sont enregistrées dans une base SQLite via des routes JSON.

Les activités sont écrites dans un langage de balisage maison (fichiers .md) : un analyseur les découpe en blocs, puis chaque bloc est rendu en HTML par une fonction Python. Le site complet est généré une fois pour toutes en pages statiques.

Mise en page en CSS pur ; toutes les couleurs, tailles et polices viennent de fichiers de thème .palette, injectés en variables CSS. Interactions en JavaScript standard, sans aucune bibliothèque externe.

Les outils de conception (atelier 3D, simulateur de structures) tournent dans le navigateur : WebGL pour l'affichage 3D et WebAssembly pour les calculs de géométrie. Aucune ressource n'est chargée depuis l'extérieur : tout est hébergé ici.
