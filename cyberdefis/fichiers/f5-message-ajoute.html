F5 — Le message ajouté

Énoncé

Télécharge image.png : elle s'affiche normalement. Un texte a pourtant été ajouté à la fin du fichier, après l'image. Ouvre le fichier autrement pour le lire.

⬇ Télécharger image.png

Format attendu : FLAG{…}

Méthode. Un fichier image peut aussi s'ouvrir avec un éditeur de texte : clic droit, « Ouvrir avec », puis le Bloc-notes. Le début du fichier est illisible — c'est l'image ; fais défiler jusqu'en bas, où un passage lisible a été ajouté.
